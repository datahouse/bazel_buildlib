# Bazel Setup

- Download [bazelisk](https://github.com/bazelbuild/bazelisk/releases) and add it to your `PATH`.
- Symlink `bazel` to `bazelisk` (optional, but recommended).
- Download [ibazel](https://github.com/bazelbuild/bazel-watcher/releases) (optional, but recommended).
- Install [Docker](https://docs.docker.com/engine/install/) and the [Compose Plugin](https://docs.docker.com/compose/install/linux/)
